E-Commerce Sales and Customer Analytics

Project Overview

This project analyzes e-commerce sales performance, customer behavior, and order trends using the Olist dataset.

Tools & Technologies

- Python
- Pandas and NumPy
- SQL (MySQL)
- Jupyter Notebook
- Power BI

Project Objectives

- Analyze sales and revenue trends.
- Understand customer purchasing behavior.
- Analyze order status and delivery performance.
- Identify business insights from e-commerce data.
- Create meaningful visualizations and dashboards.

Dataset

Olist Brazilian E-Commerce Public Dataset.

Project Work

- Data cleaning and preprocessing using Python.
- Exploratory Data Analysis (EDA).
- SQL queries for business analysis.
- Data visualization and dashboard development.

Expected Outcome

Generate meaningful business insights to support data-driven decision-making.
